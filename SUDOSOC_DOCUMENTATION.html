1. Project Overview

SudoSoc is an enterprise-grade AI-powered Intrusion Detection and Prevention System (IDS/IPS). It leverages behavioral traffic analysis and machine learning to secure network environments.

2. Features Matrix

  • Hybrid Detection: Heuristics + Stacking Ensemble (RF + XGB).
  • Encrypted Anomaly Detection: Entropy-based analysis of TLS/SSL streams.
  • LLM Threat Verification: Natural language explanations via HuggingFace.
  • Active Response: Automated firewall blocking using netsh.
  • Modern Dashboard: Real-time traffic visualization with Streamlit.

4. Technical Features & Implementation

4.1 Behavioral Generalization

We have removed raw IP addresses from the training process. The model now identifies attacks based on flow density, packet-to-byte ratios, and port behavior, making it resilient to new IP ranges.

4.2 Stacking Ensemble

The system uses a Stacking Classifier with a Logistic Regression meta-learner to combine the strengths of Random Forest and XGBoost, achieving superior accuracy on complex datasets.
