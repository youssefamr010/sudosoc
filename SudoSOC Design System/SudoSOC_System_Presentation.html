Multi-layered inspection

The 3-Layer Hybrid Threat Detection Architecture

Layer 1 (Signatures): Ultra-fast deterministic rule check mapping ports heuristics and Zeek/Suricata alerts.
Layer 2 (Ensemble ML Stacking): Advanced stacking model (XGBoost + Random Forest) providing 98.8% classification precision.
Layer 3 (GenAI Analyst): Local pipeline triggering Qwen 2.5 / Llama 3.3 analyst logs, MITRE mappings, and auto-generated rules.
Core Presentation Takeaway

Combining signature speed, statistical machine learning weights, and linguistic LLM reasoning achieves defense-in-depth.

Stacking Classifier Validation: XGBoost Confusion Matrix

Evaluates the mathematical precision of our Layer 2 XGBoost stacking baseline across 102,398 network flow samples.
Identifies 16,910 true positive attacks and classifies 84,294 normal benign network operations flawlessly.
